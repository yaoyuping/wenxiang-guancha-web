# 闻香观茶 · 香茶书房

基于用户提供的微信小程序 **V1.23.0-rc.1** 迁移的静态网页版，适配手机和电脑，部署到 GitHub Pages。

网站：https://yaoyuping.github.io/wenxiang-guancha-web/

## 已迁移

- 12 个香茶学习单元，87 篇课程与单元回顾，36 篇新版图鉴。
- 28 篇知识百科、84 篇进阶资料、66 篇原版课程；合计 301 篇内容。
- 1,084 道题目、参考答案与解析，6 组跨主题复习、10 条阶段研读路径、38 条术语。
- 原有 472 张图片，逐文件 SHA-256 核对；保留正文、配图来源、署名与许可信息。手绘素材沿用原工程，不表示实物照片。
- 阅读进度、收藏、笔记、作答记录。
- 珍藏档案、批次、入库、库存调整、分装、流水冲正。
- 品茶、闻香和日常手记；逐泡／逐段观察、参数、草稿；关联真实批次的用量扣减，编辑／撤销会冲正原消耗。
- 本机照片保存、查看与移除。网页完整备份包含网页添加的照片原件与已保存草稿。
- 网页备份，以及小程序 V1/V2/V3/V4、本机珍藏 JSON 的导入预览。校验后只补缺失记录，保留当前冲突记录和完整关联库存。

## 保存与迁移

个人记录只保存在**当前设备、当前浏览器、当前网站地址**的 IndexedDB 中，不上传到 GitHub，不调用微信 CloudBase。换浏览器、清理网站数据或无痕会话结束可能丢失本机资料，请定期下载备份。

1. 在小程序导出 V4 文字备份，另行保存私人照片原件。本机珍藏另用其导出入口。
2. 在网页的「我的 → 备份与恢复」选择 JSON，查看新增数量、冲突与缺失照片说明。
3. 点击确认，先下载当前网页资料的安全备份，再执行一次原子写入。重复导入不重复建档。
4. 小程序文字备份中的私人图片原件不能自动恢复，需从自己的归档重新添加。原图片说明及原始备份随网页数据保留。
5. 以后使用「下载完整备份」，保存到下载目录后手动另存到 iCloud Drive。没有自动 iCloud 同步。

网页不登录微信。旧备份的哈希校验确认内容完整性，不代表已认证微信身份；只能导入本人持有的文件。旧本机珍藏备份原格式没有哈希，会明确提示。

自学练习的答案随网页提供，不能作为保密考试系统。课程的原稿状态与来源说明沿用原工程，迁移不等于新增学术审订。

## 本地运行

需要 Node.js 22 或更高版本，以及 Python 3（也可使用其他静态 HTTP 服务器）。

```sh
npm ci
npm test
npm run build
npm run serve
```

打开 http://localhost:4173 。不能直接双击 HTML 使用；保存、模块和离线缓存需要 HTTP/HTTPS。

`dist/` 是构建输出。路径均相对当前目录，路由使用 URL hash，兼容 GitHub Pages 的仓库子路径。

## GitHub Pages 部署

仓库 Settings → Pages → Source 选择 **GitHub Actions**。推送到 `main` 后，`.github/workflows/pages.yml` 自动运行测试、构建并发布。仓库只包含程序、课程与教学素材，不包含个人记录或云端凭据。

已打开过的课程与配图在浏览器缓存允许时可离线阅读；未缓存的文章需联网打开。更新后关闭本站所有标签页再重新打开。持久存储请求不能替代文件备份。

## 工程说明

- `src/app.js`：网页界面与路由。
- `src/storage.js`：IndexedDB 事务、版本冲突保护，只有事务完成才提示成功。
- `src/state.cjs`：备份、导入预览和跨格式迁移。
- `src/domain/`：从 V1.23 复用的纯业务校验，不含云 SDK 或身份凭据。
- `static/data/`：由原始内容无损展开的正文、题目和索引；图片链接改为网站相对路径。
- `SOURCE-MANIFEST.json`：源版本、内容数量与教学图片哈希。
- `scripts/import-source.cjs`：从原 V1.23 工程重新导入内容，需传入包含 `miniprogram/` 与 `cloudfunctions/` 的原工程目录；日常构建不依赖原压缩包。
- `docs/VERIFICATION.md`：迁移验证范围与结果。

原业务规则的两个调整：浏览器中用纯 JavaScript SHA-256 替代 Node crypto；移除 CloudBase 的 80 次写入事务上限，IndexedDB 以单个完整快照原子提交。仍保留原数据容量、字段、版本与关联库存校验。未迁移云端登录、云同步和微信文件分享 API；网页对应使用本机保存、浏览器文件选择与下载。
